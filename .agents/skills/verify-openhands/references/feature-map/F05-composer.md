# F05 — Composer, slash commands and plan mode

The composer is the input box at the bottom of the home page and of every
conversation. A user types a message (Enter sends, Shift+Enter adds a line),
attaches files and images, picks the LLM profile for the running conversation,
watches and compacts the context window, stops and resumes the agent, and types
`/` for built-in commands (`/btw`, `/model`, `/goal`, `/plan`, `/code`) and
skills. `/plan` hands the next message to a planning agent whose PLAN.md card
can be viewed and built; Ctrl/Cmd+Enter builds it.

Source: `src/components/features/chat/`, `src/components/features/controls/tools-context-menu.tsx`, `src/components/features/controls/agent-status.tsx`, `src/hooks/chat/`, `src/utils/constants.ts`.

## Sub-features

- `F05.send-message`: Send is disabled while the field is empty; Shift+Enter inserts a newline; Enter sends, clears the field and the message persists after reload.
- `F05.draft-persistence`: unsent text is restored per conversation (after navigation and reload) and on the home composer.
- `F05.composer-resize`: the field grows with its content and shrinks when cleared; an invisible top-edge grip (resize cursor, no line drawn) lets the user drag the height.
- `F05.plus-menu`: `+` opens a tools menu (Macros, Show skills/hooks/agent tools, Add Files and Images; Git tools in a repository); a macro fills the composer without sending.
- `F05.agent-profile-switch`: before a conversation starts, `+` > Switch agent profile lists agent profiles and links to Manage agent profiles; it is absent in a started conversation.
- `F05.agent-profile-pill`: before a conversation starts, the composer shows an agent-profile pill (robot icon, `Switch agent profile: <name>`) next to the model pill; it opens the same profile list, closes on an outside click and on Escape (focus back on the pill; Known failure (reproduced 2026-10-27, [#18808](https://github.com/OpenHands/OpenHands/issues/18808)): Escape leaves it open, and the model pill's popover the same), is the first control to drop when the row is narrow (hidden at 390 px and 320 px) and is absent in a started conversation. Source: `src/components/features/chat/components/chat-input-profile-picker.tsx`, `src/components/features/chat/components/chat-input-actions.tsx`.
- `F05.attach-files`: picked files show as chips and images as thumbnails (with an Upload-as-file toggle), each removable; sent files land in the workspace and are named in the message.
- `F05.attach-size-limit`: a file over 3 MB, or a selection over 3 MB in total, is refused with an error toast.
- `F05.image-only-send`: an attached image alone, with an empty field, enables Send; the sent user message shows the thumbnail and carries the picture as an embedded data URL.
- `F05.paste`: pasted clipboard text is inserted as plain text; pasted images and dropped files attach.
- `F05.dictation`: the mic button dictates into the composer; without a microphone it toasts a failure and resets.
- `F05.llm-profile-picker`: the model pill switches the running conversation's LLM profile; the next reply uses the new model. On Home the pill picks the LLM profile the next conversation launches with, on a local backend and on a Cloud backend (where it lists the organization's LLM profiles, the pick persists after a reload, and the conversation started from Home runs on it).
- `F05.profile-identity`: the pill names the profile the conversation was started with, also after a reload and when another profile uses the same model; changing the default profile in Settings changes the home pill, not an existing conversation's.
- `F05.overflow-menu`: at very narrow widths the model pill collapses into a "More input actions" menu whose Model submenu fits the viewport and switches the profile; Escape closes the menu and returns focus to its trigger.
- `F05.context-window-meter`: the ring shows context use; its popover opens the Usage tab and compacts the context. Above 70% the popover's percentage and bar fill use the theme's warning color and above 90% its error color, on a raised surface with a bordered track, readable in light and dark themes.
- `F05.stop-resume`: Stop pauses a running agent (status `Stopped`, Play button); Play resumes it.
- `F05.queued-message`: a follow-up typed while the agent runs is accepted and answered.
- `F05.slash-menu`: `/` opens a filtered command list (built-ins and skills) with arrow, Tab/Enter and Escape handling.
- `F05.slash-model`: `/model` lists saved profiles; `/model <name>` switches profile.
- `F05.slash-btw`: `/btw <question>` answers a side question in a dismissible card without adding to the main stream; a bare `/btw` toasts that a question is needed.
- `F05.slash-goal`: `/goal [--max N] <objective>` runs a judged goal loop with a status banner, Stop and Resume; only the newest goal status offers Resume.
- `F05.slash-plan-code`: `/plan` switches to plan mode (a planner sub-conversation), `/code` switches back.
- `F05.slash-plan-code-task`: `/code <task>` switches to code mode and sends `<task>` to the code agent at once; `/plan <task>` switches to plan mode and sends `<task>` to the existing planner.
- `F05.plan-preview`: the planner's Plan.md card shows the plan with Read more, View (Planner tab) and Build.
- `F05.build-plan-shortcut`: Ctrl/Cmd+Enter in plan mode builds the plan with the code agent.
- `F05.phone`: the composer fits a 390 px viewport with every control inline.

## How to get to it (user POV)

- Home page composer (`/`) and the composer of any conversation (`/conversations/<id>`, reached from the sidebar conversation list or by URL).
- `+` (More actions, `chat-plus-button`) inside the composer opens the tools menu; its last item **Add Files and Images** opens the native file picker (`upload-image-input`).
- Agent-profile pill (`chat-input-agent-profile`) next to `+` before a conversation starts (Home, or an empty new conversation), when the backend has agent profiles.
- Model pill (`chat-input-llm-profile`) next to `+`; at 320 px it moves into the vertical-dots **More input actions** button. On the home page it names the default profile (the one Settings → LLM marks as default); in a conversation it names the profile that conversation runs on.
- Right side of the composer: status text with Stop/Play, context ring (`context-window-meter`), mic (`chat-dictation-button`), Send (`submit-button`).
- Typing `/` at the start of a word opens the slash menu (`slash-command-menu`); `/plan` and `/code` are the only mode switches on the local backend (the Code/Plan pill is Cloud only).
- Keyboard: Enter sends, Shift+Enter newline, Ctrl+Enter / Cmd+Enter builds a plan; Escape closes the slash menu.

## Gotchas

- Always export your own `OH_VERIFY_RUN`. `launch --new` repoints the shared `current` symlink, and another agent relying on `current` drove and then stopped this family's stack mid-run. If the URL jumps to a page you never opened or `fetch failed` appears, run `control-openhands status` before blaming the product.
- `conversation wait <id>` right after sending returns at once with the previous `finished` status. Use `conversation wait <id> --fresh`; `--until running` then a terminal wait only works for turns longer than the poll interval (a `Reply with only` turn on deepseek-flash can finish first, and `--until running` then times out).
- The slash menu stays open while you type a command; press Escape before Enter or Enter selects the highlighted option instead of sending.
- Conversation drafts are saved 500 ms after the last keystroke and flushed on navigation and unmount, so text typed just before leaving comes back.
- Escape closes the `+` tools menu (`browser count 'testid=tools-context-menu'` is `0`) and returns focus to `chat-plus-button`, whether focus was on the trigger or on a menu item. A menu left open covers attachments in screenshots. Escape also closes the narrow-width "More input actions" overflow menu (`browser count 'testid=chat-input-overflow-menu'` is `0`, the trigger's `aria-expanded` is `false`) and returns focus to the trigger, whether focus was on the trigger, on `overflow-model-button` or on a profile row of the open Model submenu (#18174).
- After a client-side switch between conversations (a sidebar row, or a user-message branch in `F06.branch-from-here`) Send keeps the previous conversation's state (Known failure, [#18202](https://github.com/OpenHands/OpenHands/issues/18202), reproduced 2026-10-16). Switching from an empty composer to one with a saved draft restores the text next to a disabled Send; this is a race (Send came up enabled in 1 of 7 tries), so one enabled reading does not show the bug is gone. Switching from a composer with text to an empty one leaves Send enabled, and clicking it does nothing. Typing or `browser reload` fixes it, and Enter in the field sends the restored text anyway. Read `browser enabled 'testid=submit-button'` after a reload, or after typing.
- Expected: a prompt that a suggestion chip (`testid=chat-suggestions`) or a `+` > **Macros** item writes into the composer enables Send at once. Known failure (reproduced 2026-10-09, [#18202](https://github.com/OpenHands/OpenHands/issues/18202)): on a new No workspace conversation, `browser click 'testid=chat-suggestions >> text=Fix README'` (or `browser click 'testid=chat-plus-button'`, `browser hover 'testid=macros-button'`, `browser click 'testid=fix-readme-button'`) fills the field, but `browser enabled 'testid=submit-button'` is `false` (5 of 5 tries at desktop; a race at phone) until a character is typed. Both paths call `setMessageToSend`, which writes the text without an input event.
- Uploaded chips and thumbnails have no test ids. Their remove buttons are named `Remove <file name>` (file chip) and `Remove image` (thumbnail), and Send, Stop and Play read `Send message`, `Stop` and `Resume the agent task` (#18033); select by those names, or by text/alt.
