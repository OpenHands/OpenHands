# F05 — Composer, slash commands and plan mode

The composer is the input box at the bottom of the home page and of every
conversation. A user types a message (Enter sends, Shift+Enter adds a line),
attaches files and images, picks the LLM profile for the running conversation,
watches and compacts the context window, stops and resumes the agent, and types
`/` for built-in commands (`/btw`, `/model`, `/goal`, `/plan`, `/code`) and
skills. `/plan` hands the next message to a planning agent whose PLAN.md card
can be viewed and built; Ctrl/Cmd+Enter builds it.

Source: `src/components/features/chat/`, `src/components/features/controls/tools-context-menu.tsx`, `src/components/features/controls/agent-status.tsx`, `src/hooks/chat/`, `src/utils/constants.ts`.

## Sub-features

- `F05.send-message`: Send is disabled while the field is empty; Shift+Enter inserts a newline; Enter sends, clears the field and the message persists after reload.
- `F05.draft-persistence`: unsent text is restored per conversation (after navigation and reload) and on the home composer.
- `F05.composer-resize`: the field grows with its content and shrinks when cleared; a top-edge grip lets the user drag the height.
- `F05.plus-menu`: `+` opens a tools menu (Macros, Show skills/hooks/agent tools, Add Files and Images; Git tools in a repository); a macro fills the composer without sending.
- `F05.agent-profile-switch`: before a conversation starts, `+` > Switch agent profile lists agent profiles and links to Manage agent profiles; it is absent in a started conversation.
- `F05.attach-files`: picked files show as chips and images as thumbnails (with an Upload-as-file toggle), each removable; sent files land in the workspace and are named in the message.
- `F05.attach-size-limit`: a file over 3 MB, or a selection over 3 MB in total, is refused with an error toast.
- `F05.paste`: pasted clipboard text is inserted as plain text; pasted images and dropped files attach.
- `F05.dictation`: the mic button dictates into the composer; without a microphone it toasts a failure and resets.
- `F05.llm-profile-picker`: the model pill switches the running conversation's LLM profile; the next reply uses the new model.
- `F05.overflow-menu`: at very narrow widths the model pill collapses into a "More input actions" menu with a Model submenu.
- `F05.context-window-meter`: the ring shows context use; its popover opens the Usage tab and compacts the context.
- `F05.stop-resume`: Stop pauses a running agent (status `Stopped`, Play button); Play resumes it.
- `F05.queued-message`: a follow-up typed while the agent runs is accepted and answered.
- `F05.slash-menu`: `/` opens a filtered command list (built-ins and skills) with arrow, Tab/Enter and Escape handling.
- `F05.slash-model`: `/model` lists saved profiles; `/model <name>` switches profile.
- `F05.slash-btw`: `/btw <question>` answers a side question in a dismissible card without adding to the main stream.
- `F05.slash-goal`: `/goal [--max N] <objective>` runs a judged goal loop with a status banner, Stop and Resume.
- `F05.slash-plan-code`: `/plan` switches to plan mode (a planner sub-conversation), `/code` switches back.
- `F05.plan-preview`: the planner's Plan.md card shows the plan with Read more, View (Planner tab) and Build.
- `F05.build-plan-shortcut`: Ctrl/Cmd+Enter in plan mode builds the plan with the code agent.
- `F05.phone`: the composer fits a 390 px viewport with every control inline.

## How to get to it (user POV)

- Home page composer (`/`) and the composer of any conversation (`/conversations/<id>`, reached from the sidebar conversation list or by URL).
- `+` (More actions, `chat-plus-button`) inside the composer opens the tools menu; its last item **Add Files and Images** opens the native file picker (`upload-image-input`).
- Model pill (`chat-input-llm-profile`) next to `+`; at 320 px it moves into the vertical-dots **More input actions** button.
- Right side of the composer: status text with Stop/Play, context ring (`context-window-meter`), mic (`chat-dictation-button`), Send (`submit-button`).
- Typing `/` at the start of a word opens the slash menu (`slash-command-menu`); `/plan` and `/code` are the only mode switches on the local backend (the Code/Plan pill is Cloud only).
- Keyboard: Enter sends, Shift+Enter newline, Ctrl+Enter / Cmd+Enter builds a plan; Escape closes the slash menu.

## Gotchas

- Always export your own `OH_VERIFY_RUN`. `launch --new` repoints the shared `current` symlink, and another agent relying on `current` drove and then stopped this family's stack mid-run. If the URL jumps to a page you never opened or `fetch failed` appears, run `control-openhands status` before blaming the product.
- `conversation wait <id>` right after sending returns at once with the previous `finished` status. Wait for `--until running` first, then for the terminal state.
- The slash menu stays open while you type a command; press Escape before Enter or Enter selects the highlighted option instead of sending.
- Conversation drafts are saved 500 ms after the last keystroke and not flushed on unmount (the home draft is): navigating sooner restores the older draft (fail row). Wait a second before navigating when testing restoration.
- Escape does not close the `+` tools menu; click `chat-plus-button` again or choose an item. A menu left open covers attachments in screenshots.
- Uploaded chips and thumbnails have no test ids; Send, Stop/Play and the attachment remove buttons have no accessible name (fail row). Select by text/alt as above.
- `browser upload` feeds the hidden input directly; the `+` > Add Files and Images item only opens the native picker, which the CLI cannot drive.
- The `Switched to profile` notes are client-side and gone after reload; assert the pill and `conversation status`.
- `/plan` messages go to a separate planner conversation; the browser stays on the parent `/conversations/<id>`, so wait on the planner id from `conversation list`.
- After a goal is resumed, the old `interrupted` banner still offers `Resume` (also after reload); clicking it again starts another loop.
- Opening the context popover logs a 404 for `/api/llm/balance` on the local backend in `browser errors --app-only`; it does not break the popover.
- `--observe` takes CSS selectors (`'[role=status]'`), not `role=` selector syntax.
