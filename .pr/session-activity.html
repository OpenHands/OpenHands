Keep startup in the conversation activity group

Initialization, reasoning and consecutive tools share one expandable group until visible agent content begins. A completed group summarizes actual tool work; without tools it retains “Initialized session” or “Resumed session.”

Presentation history only: no SDK event, API or version changes. Startup details persist in sessionStorage for this tab and remain scoped to backend, organization and conversation. Other tabs/devices still show their recorded agent history without invented startup steps.

+function readEntries(value: unknown): Record<string, SessionActivity[]> {
+  if (
+    !value ||
+    typeof value !== "object" ||
+    !("entries" in value) ||
+    !value.entries ||
+    typeof value.entries !== "object"
+  )
+    return {};
+  return Object.fromEntries(
+    Object.entries(value.entries).filter(
+      ([, entries]) =>
+        Array.isArray(entries) &&

+            entry &&
+            typeof entry.id === "string" &&
+            ["initialize", "resume"].includes(entry.kind) &&
+            Number.isFinite(entry.startedAt) &&
+            ["pending", "complete", "failed"].includes(entry.phase) &&
+            typeof entry.open === "boolean" &&
+            Array.isArray(entry.steps) &&
+            entry.steps.every((step: unknown) => typeof step === "string"),
+        ),
+    ),
+  );
