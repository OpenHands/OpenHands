# `browser record`: recordings made with it

Both takes were recorded with `control-openhands browser record` on 2026-10-09.
They ran on one run of `main` @ `ff1a1d6` (agent-server 1.53.0, Chromium 1194,
ffmpeg 6.1.1), with `deepseek-flash` as the model.

- [escape-closes-menu.mp4](escape-closes-menu.mp4) /
  [.gif](escape-closes-menu.gif): the composer's More input actions menu at
  the narrow viewport (320x700). It opens, closes on Escape with focus back on
  the trigger, opens again into the Model submenu, and closes on Escape
  (#18174). 9 s recorded, 8.3 s of video after the lead-in cut, 8 distinct
  frames.
- [send-and-reply.mp4](send-and-reply.mp4) / [.gif](send-and-reply.gif): a
  prompt typed on the home page and sent. The conversation opens and the reply
  `qa-record-ok` streams in (1440x1000, 5.9 s recorded).
