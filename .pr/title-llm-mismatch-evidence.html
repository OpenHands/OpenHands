BEFORE   On main, title generation resolved to fast (haiku) while the agent ran on powerful (sonnet) — a model mismatch.

AFTER   With this PR, resolveTitleLlmProfile consults the agent profile's pinned LLM as a mid-priority fallback, so the title is generated by powerful — the same model the agent uses.
