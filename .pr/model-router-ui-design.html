Runtime model router UI

This PR is the Canvas companion for the software-agent-sdk model-router work. It adds an optional conversation-header control that appears only when the runtime supports the new model-router status endpoint. The control lets testers add existing LLM profiles as routes and manually switch routes without waiting for a released @openhands/typescript-client package.

API shape

Canvas consumes the SDK PR routes directly

Before, the chat UI could only live-switch by LLM profile through /switch_profile. That path replaces the conversation LLM directly and keeps profile switching as the UI concept.

After, the new control treats the model router as the state owner: GET /model_router reads routes and selection, POST /model_router/routes adds a profile-backed LLM route, and PATCH /model_router manually selects or resumes automatic routing.
