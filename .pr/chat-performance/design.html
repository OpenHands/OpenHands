OpenHands / Agent Canvas · performance design

Keep conversation updates proportional to the work

Long conversations repeatedly search their retained history while the agent runs. Typing also broadcasts composer state that often has not changed. This patch removes those avoidable costs without changing the transcript or scroll model.

★ Reuse one action index, append reasoning once per group, and notify conversation subscribers only when suggestion visibility changes.
