LIVE INTEGRATION EVIDENCE — HISTORY READINESS

Scope and limitation
This is zero-model real-app integration/recovery smoke, not a reproduction of
the exact failed-initial-REST / WebSocket-OPEN-before-replay race. The unmodified
verification CLI can terminate/restart the real Agent Server and observe its
WebSocket lifecycle; it cannot selectively fail the REST history request while
holding WebSocket replay. No route interception, synthetic replay, model
responses, driver changes, fixture changes, or feature-map changes were used.
The exact race is covered separately by the product regression tests.

Procedure (all CLI calls use an explicit isolated --run, or OH_VERIFY_RUN)
1. control-openhands launch --new --run-id <id> --build auto --print-run
2. control-openhands doctor
3. QA_HISTORY_DUMMY_KEY=qa control-openhands llm set --profile default \
   --model openai/gpt-4o --base-url http://127.0.0.1:9 \
   --api-key-env QA_HISTORY_DUMMY_KEY --no-validate
4. control-openhands onboard --skip (analytics off)
5. browser record start --feature F06.empty-state-suggestions --fps 10
6. browser click testid=conversation-panel-new-thread-picker
   browser click testid=launch-no-workspace --expect-url /conversations/
   browser text testid=chat-suggestions
   browser click testid=event-group-toggle
   browser attr testid=event-group-toggle aria-expanded
   browser screenshot; browser viewport phone; browser screenshot
   browser record stop --gif
7. api POST /api/conversations --write --data <idle conversation request>
   Request: Agent with tools=[] and include_default_tools=[], dummy loopback
   LLM profile above, owned run workspace, autotitle=false, max_iterations=1.
   No initial message and no run/start call.
8. api POST /api/conversations/<id>/events --write --data
   {"role":"user","content":[{"type":"text","text":"QA persisted history marker — no agent execution requested."}],"run":false}
9. browser viewport desktop; browser record start --feature F06.reconnect --fps 10
   browser goto /conversations/<id>; browser wait testid=user-message
   browser count testid=chat-suggestions; browser reload
   browser wait testid=user-message; browser screenshot
   browser viewport phone; browser reload; browser wait testid=user-message
   browser count testid=chat-suggestions; browser screenshot
10. service stop agent-server; inspect Reconnecting UI; restart
11. api POST /api/conversations/<id>/events --write --data
    {"role":"user","content":[{"type":"text","text":"QA recovery marker — received after server restart."}],"run":false}
    browser wait-text 'QA recovery marker'; browser screenshot
    browser viewport desktop; browser screenshot
    browser text testid=user-message; browser count testid=chat-suggestions
    browser record stop --gif; conversation status <id>; doctor
12. browser events --kinds websocket-created,websocket-open,websocket-close
    (CLI websocket-open means first observed frame, not an exact handshake clock.)
13. stop --purge-private

Only the owned isolated run was stopped/purged. No model calls or provider
validation were requested; dummy model endpoint was loopback port 9. No private
run state, model key, session key, storage state, or unredacted network payloads
are included in this artifact directory.
