CONVERSATION STARTUP & RESUME · REVIEW GUIDE

Keep the conversation in place while it starts

Cloud launch now occupies the same shell as a connected chat. Pending prompts keep their collapsed height, detailed progress stays in the thread, and a stable sidebar row shares the header title from the submitted prompt through generated naming.

★ The shared layout fixes the prompt/composer jump. This is presentation work: sandbox lifecycle and event delivery are unchanged. Completed startup tasks now remain visible until their saved list row arrives, and title presentation observes existing caches; the active-conversation query checks pending titles every three seconds for at most the first minute, without accelerating full-sidebar polling. Start with the changed files and ConversationLaunchView.

Evidence: the PR includes real Cloud before/after startup, resume and phone recordings plus a real Local model response. These diagrams explain source changes; they are not product screenshots. Existing history may still arrive during resume and move later messages.
