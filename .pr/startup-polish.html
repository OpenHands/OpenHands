CONVERSATION STARTUP & RESUME · REVIEW GUIDE

Keep the conversation in place while it starts

Cloud launch now occupies the same shell as a connected chat. Pending prompts keep their collapsed height, and detailed progress stays in the thread while the composer retains useful color and controls.

★ The shared layout fixes the prompt/composer jump. This is presentation work: request timing, sandbox lifecycle, event delivery and durable state are unchanged. Start with the changed files and ConversationLaunchView.

Evidence: the PR includes real Cloud before/after startup, resume and phone recordings plus a real Local model response. These diagrams explain source changes; they are not product screenshots. Existing history may still arrive during resume and move later messages.
