Factories: Add Automation inside a factory

Recorded against a real automation service built from OpenHands/automation#751 (feat/factories). The Automations icon matches Automate. Add Automation in Core SDLC creates the automation in that factory, Factories stays selected in the sidebar, and the count goes from 2 to 3. The same flow from the Automate dashboard creates an automation in no factory and Automate stays selected. Git Sync stays on the Automate dashboard only.
