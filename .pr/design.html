Mechanical changes: localized long-wait copy in all 16 locale blocks; focused regression tests for timing, active socket selection, lifecycle gating and failed-message ownership.

Background refreshes retain their cached result

query-client-config.ts: previously, a transient failure after retry exhaustion could toast even when the page retained useful data. Now the query still exposes its error, but cached refresh failures classified by isTransientRequestError omit the global toast. Initial loads, nontransient errors and mutations keep their existing feedback. This applies across backend modes; it does not change retry schedules or claim stale data is current. The shared transient classifier also recognizes the SDK wrapper whose cause is the original fetch TypeError, preserving the existing finite retry budget.

Tests exercise cached 503 recovery, an initial 503, cached 403 and existing mutation/authentication handling. The local server-stop recording also exercises real polling failures.

Compatibility and limits

PathEffect
Local / CloudBoth use shared transport feedback. STARTING/PAUSED gating and resume toast ownership concern Cloud metadata.
Code / Plan / delegatedMain and planning socket progress are independent. Delegated conversations opened as a conversation use the same provider. No change to background child execution.
OpenHands / ACPTransport presentation is shared. Agent error classification and authentication actions remain unchanged.
Standalone / embeddedShared React components and theme tokens. App and library builds are required.
Backend and storageNo new endpoint, wire field, SDK minimum, migration or persisted setting. Existing retry/backoff and event replay remain unchanged. Retry reconnects; it does not resubmit messages.

Stacked on #19187 for explicit pending-message resume status. That status owns the conversation feedback while a message waits for the sandbox.
