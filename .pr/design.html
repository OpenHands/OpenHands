OpenHands #16905 · Canvas-only overlay

Claude ACP skill overlay

Claude Code ACP launches from agent_profile_id. The server then strips agent_context.skills. Canvas now appends enabled catalog instructions through agent_launch_additions.system_message_suffix_append so they still reach Claude's first prompt.

10 files · +906 / −3 · head 56c0e6e55 · merge-base 410b6296a

1What changed

★ Stay on the ACP profile path. Do not send skills_append on agent-server 1.46 — AgentLaunchAdditions is extra="forbid" and only accepts system_message_suffix_append (max 32768). See agent-server-adapter.ts:1348.

Activation is pointer-only, so global agent_settings is often still OpenHands when Claude is active. An ACP default profile must keep launching via agent_profile_id. The overlay reads acp_server / acp_command from the profile detail, not from that stale settings blob.
