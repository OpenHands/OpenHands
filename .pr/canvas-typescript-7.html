One TypeScript compiler for Canvas

Canvas already runs the TypeScript 7 compiler. This change removes the TypeScript 6 copy that old lint tools still load.

Before → after

  • Build and typecheck: the native compiler alias becomes a direct typescript@7.0.2 pin.
  • ESLint: the Oxc parser replaces the TypeScript 6 parser. Canvas keeps its React, accessibility, translation, Tailwind, and local rules.
  • TypeScript lint rules: Oxlint handles TypeScript-specific rules, including type-aware optional chaining.
  • Query return check: the TypeScript 7 checker rejects functions that return missing data, which the syntax-only Query plugin cannot detect.

Review focus

The native checker exports an unstable API. Keep its usage in the query-return script and run the regression test when bumping TypeScript. The upgrade does not change Canvas runtime APIs.
