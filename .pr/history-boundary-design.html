The provider and hook are shared by standalone and embedded Canvas. unchanged transport:75 · shared provider:542 · live writer:183

BoundaryDecision
API and compatibilityNo server endpoint, wire field, client package or compatibility-floor change. The optional store argument preserves existing callers.
Request and render costThe 50-event request size remains. Streaming updates do not gain sorting work. Virtualization and retained-history memory limits are separate work.
Related fixes#19041 covers planner-derived timestamp anchors. #17560 and #19620 cover UI projection of events already received. This PR does not reimplement them.
Existing limitationsCursorless history keeps the legacy timestamp fallback and its limitations. Recovering a disjoint middle gap after a long absence is separate from continuing the retained older-history frontier.

The interface remains compatible; the behavior risk is page-frontier state across asynchronous loads. The focused tests target ownership, retries, remounts and exhaustion, while the real Local check verifies visible ordering at the actual page boundary.
