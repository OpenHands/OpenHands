Behavior change

Before: Needs review

Any completed run with a finish response but no recognized status was treated as unknown, including a response containing only outcome_summary.

After: Successful

A completed run now defaults to success when the response omits status. The outcome summary is still displayed. Explicit unrecognized status strings still require review.
