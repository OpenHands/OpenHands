Hardening bundle: launch, packaging, and CI

Nine independent hardening gaps found by one review sweep, fixed in nine focused commits: Electron MARS IPC sender validation, a single-instance lock, ACP loopback binding, one container route table, a published-package smoke test, SHA-pinned release workflows, WebSocket-safe Helm defaults, checksum-verified runtime downloads, and a testing-matrix that matches CI.

1What the sweep found

★ The two security-critical items — MARS IPC accepting events from any renderer, and the ACP example publishing the agent-server unauthenticated on every interface — are the ones a maintainer should read first; the rest are robustness and supply-chain hygiene.

Findings were established by code inspection with line anchors (tracked in #19962); none had a pre-existing issue.
