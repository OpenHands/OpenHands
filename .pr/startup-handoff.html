PR design • startup / resume

Keep connection progress inside the session group

A READY sandbox can still have a connecting browser socket and an unconfirmed user message. The activity group now owns progress until both settle, so a second status row never pushes it down.

The measured baseline inserted and removed 44px above the group. The fix preserves message ordering and disclosure state; ordinary message feedback and actionable errors stay available. No backend contract changes.
