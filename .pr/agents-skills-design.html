PR design note · refactor

Route contributor guidance instead of loading the whole monolith

The root AGENTS.md becomes a small, always-loaded router. Six task-specific skills hold the detailed operational rules and load only when their trigger matches the work.

1The decision

★ Reduce always-loaded guidance from 736 lines to 71 without deleting the domain knowledge: root keeps universal policy and explicitly routes to six focused skills.
90%fewer root lines
6new functional skills
12skill files: router + reference

The routing table is the load-bearing change: it names each skill and the work that should invoke it. Cross-cutting tasks may load more than one. Source: AGENTS.md:37–52.

2One context blob becomes progressive disclosure

ⓘ Each SKILL.md stays around 150–200 words and points to a detailed guide, preserving progressive disclosure inside the skill itself.

4The split moves knowledge; it does not summarize it away

Detailed sections were copied into owning references/guide.md files, then supplemented with the few operational notes formerly embedded in the root “General” section. Existing comments and the version-drift test now point to the owning skill rather than stale root headings.
