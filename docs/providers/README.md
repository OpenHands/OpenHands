# LLM Providers

This directory contains documentation for various LLM providers that can be used with OpenHands.

## Available Providers

- [AI Badgr](./ai-badgr.md) - A cheaper OpenAI-compatible alternative backend

## Adding a New Provider

If you'd like to add documentation for a new provider, please:

1. Create a new markdown file in this directory
2. Include setup instructions, code examples, and any provider-specific configuration
3. Update this README to include a link to your provider documentation
4. Submit a pull request

For questions or suggestions, please open an issue or join us on [Slack](https://dub.sh/openhands).
