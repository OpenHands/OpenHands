# OpenHands Documentation

Welcome to OpenHands! This folder will contain guides, tutorials, and setup instructions for new contributors.

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Create a new branch
4. Make your changes
5. Submit a pull request

## Contributing

We welcome contributions! Check out the [Good First Issues](https://github.com/All-Hands-AI/OpenHands/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) to get started.
