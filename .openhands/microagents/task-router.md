# Discovery-First Task Router

Before editing, inspect the repository guidance, current implementation, configuration, and relevant tests. Convert the request into concrete acceptance criteria, identify security and compatibility risks, and select the smallest upstream-compatible solution.

Preserve unrelated work. Search locally before creating new abstractions or adding dependencies. Plan verification before implementation. After implementation, critique the result against the acceptance criteria and correct clear gaps.

Never commit secrets, expose complete credentials, use destructive Git cleanup, or claim validation that was not run. Finish with the files changed, validation results, manual steps, assumptions, and unresolved risks.
