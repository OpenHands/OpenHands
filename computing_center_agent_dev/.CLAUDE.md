# 算力中心运维 CLI Agent 开发项目

## 项目概述

本项目旨在基于 OpenHands 框架开发一个专业的**算力中心运维 CLI Agent**。该 Agent 继承自 CodeActAgent，完全兼容原有能力，并扩展了 HPC 集群运维专用功能。

## 项目目标

1. **完全兼容**: 继承 CodeActAgent 的所有能力（bash、Python、文件编辑等）
2. **专业扩展**: 添加 Slurm/PBS/K8s 集群运维工具
3. **易于部署**: 可直接集成到 OpenHands 框架中
4. **高质量代码**: 遵循 OpenHands 代码规范和最佳实践

## 开发指南

### 1. 环境设置

```bash
# 克隆 OpenHands 仓库（如果还没有）
git clone https://github.com/All-Hands-AI/OpenHands.git
cd OpenHands

# 创建虚拟环境
python -m venv venv
source venv/bin/activate

# 安装依赖
pip install -e ".[dev]"
```

### 2. 集成到 OpenHands

**方法 A: 作为 agenthub 模块**

```bash
# 复制到 agenthub
cp -r computing_center_agent_dev openhands/agenthub/computing_center_agent

# 修改 openhands/agenthub/__init__.py
# 添加: from openhands.agenthub import computing_center_agent
```

**方法 B: 使用 classpath 配置**

```toml
# config.toml
[agent.ComputingCenterAgent]
classpath = "computing_center_agent_dev.agent.computing_center_agent.ComputingCenterAgent"
```

### 3. 配置示例

```toml
# config.toml

[core]
default_agent = "ComputingCenterAgent"
runtime = "docker"  # 或 "local", "cli"

[llm]
model = "gpt-4o"
api_key = "your-api-key"

[agent.ComputingCenterAgent]
# 继承的配置 (CodeActAgent)
enable_cmd = true
enable_jupyter = true
enable_browsing = false  # CLI 模式建议禁用
enable_think = true
enable_plan_mode = true

# 算力中心配置
cluster_type = "slurm"       # slurm, pbs, k8s
cluster_name = "my_cluster"
default_partition = "gpu"
enable_gpu_monitor = true
enable_job_manager = true
enable_diagnostic = true
enable_log_analyzer = true
gpu_vendor = "nvidia"

# 告警阈值
alert_gpu_util_low = 30
alert_gpu_memory_high = 90
```

### 4. 运行测试

```bash
# 运行所有测试
pytest computing_center_agent_dev/tests/

# 运行特定测试
pytest computing_center_agent_dev/tests/test_agent.py -v

# 检查覆盖率
pytest --cov=computing_center_agent_dev
```

### 5. 使用 Agent

```bash
# CLI 模式
python -m openhands.core.main \
    --config-file config.toml \
    -t "查看集群状态"

# 指定 Agent
python -m openhands.core.main \
    --agent-config ComputingCenterAgent \
    -t "提交一个 GPU 训练作业"
```

## 常见问题

### Q: 如何添加新工具？

1. 在 `tools/` 目录创建新文件
2. 定义 `create_xxx_tool()` 函数
3. 在 `tools/__init__.py` 导出
4. 在 Agent 的 `_get_computing_tools()` 中加载

### Q: 如何自定义提示词？

1. 在 `prompts/` 目录创建/修改 `.j2` 文件
2. 在配置中指定 `system_prompt_filename`

### Q: 如何支持新的调度系统？

1. 在工具的命令生成器中添加新系统的命令
2. 在配置中添加 `cluster_type` 选项
3. 更新微智能体知识库
